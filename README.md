# Reinforcement Learning FAT Workspace

This folder consolidates the previous RL CAT 1 (`rl`) and CAT 2 (`rl-2`) work into one Final FAT workspace.

## Obsidian entry point

Open this folder in Obsidian:

```text
rl-fat/study_guide
```

Start from:

```text
00_fat_rl_index.md
```

## Layout

- `study_guide/` - combined Obsidian notes from CAT 1 and CAT 2.
- `study_guide/figures/` - all figures used by both note sets.
- `source_material/cat1/` - CAT 1 source PDFs and past papers.
- `source_material/cat2/` - CAT 2 source PPTX files and any past papers if present.
- `extracted_content/cat1/` - CAT 1 extraction outputs.
- `extracted_content/cat2/` - CAT 2 extraction outputs.
- `prompts/` - original CAT prompts plus the editable FAT prompt starter.
- `scripts/` - extraction scripts copied from the original folders.
- `plans/` - previous implementation plans for reference.

The original `rl` and `rl-2` directories were left untouched as a fallback.
